Privacy policy

MyChat MCP is a personal tool that runs only on its owner's computer.

  • Google account data is accessed through Google APIs only at the owner's request.
  • OAuth tokens and any downloaded data are stored locally on the owner's machine.
  • No data is sent to, stored on, or shared with any server other than Google's own APIs.
  • No data is sold, shared with third parties, or used for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
